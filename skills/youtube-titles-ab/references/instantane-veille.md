# Instantané de veille (septembre 2026, à rafraîchir)

Partie du skill youtube-titles-ab, lue seulement quand la collecte de l'étape 1 est impossible.

Repli quand la collecte de l'étape 1 est impossible, ou contexte à comparer avec les références fraîches. Ce n'est pas une source de preuve : ces constats datent et ne remplacent pas les références collectées pour la vidéo.
- **Anglais** : format en série très répété, « ChatGPT vs Claude Make [X] From Scratch », souvent avec les numéros de version (« ChatGPT 6 Astra vs Claude Fable 5.1 Make Minecraft Shaders »). Le sujet « shaders Minecraft par IA » y est déjà traité plusieurs fois, et copié dans d'autres langues (ex. allemand).
- **Français** : les comparatifs IA sont surtout documentaires (« lequel faut-il utiliser en 2026 ») ; le format duel gaming est rare, donc à occuper. Accroches qui existent : « … coder MINECRAFT de zéro », « Minecraft mais… ».
- **À retenir** : « de zéro » (équivalent de « from scratch ») est l'accroche récurrente de la niche ; se démarquer du format anglais par le ton gaming FR plutôt que de le traduire mot pour mot.
